## 0. 项目定义

**一句话定位**：低成本预查重工具——大学生在正式送检知网 / 维普 / 万方之前，先用本项目预估查重率，减少"查一次、改一次、反复花钱"的试错成本；预估结果通过用户回传的真实查重报告持续校准，逐步逼近目标平台真实结果。

**核心问题**：毕业论文查重单价高（知网一次几十到上百元），学生改稿往往要反复送检，成本不可控，且无法在提交前预知结果。

**目标用户**：本科 / 硕博毕业生，及需要论文查重的高校师生。

**发布形态**：
- 桌面端：本地安装使用（离线引擎 + 在线校准同步）
- 网站端：云端 Web 服务（免安装，在线查重）

## 1. MVP 功能范围（待确认，锁定后不得随意增删）

### P0（第一版必须交付）

| 功能 | 说明 | 验收要点 |
|------|------|----------|
| 文档上传查重 | 支持 docx / txt / md / pdf，分段提取 → 指纹计算 → 相似度输出 | 1 万字文档 30 秒内出结果 |
| 多方案切换 | 知网模拟方案 / 维普模拟方案 / 万方模拟方案 / 第三方 API 方案，功能可选、按平台切换 | 方案可在配置中增删 |
| 查重报告 | 总查重率 + 相似片段高亮 + 来源提示 | 报告可导出 |
| 校准训练系统 | 用户上传在某平台的真实查重报告 → 与系统预查重结果配对 → 训练校准模型 → 提升预估精度 | 模型随样本持续迭代 |
| 账号与用量 | 注册 / 登录、免费次数、积分或套餐 | 防止滥用 |

### P1（二期候选，本版不做）

- 降重改写建议
- 批量查重（目录级）
- 论文格式规范检测
- 历史报告对比

### 明确不做（防范围蔓延）

| 不做 | 原因 | 何时考虑 |
|------|------|----------|
| 承诺与知网结果完全一致 | 技术上不现实，法律上误导 | 永不承诺，报告带免责声明 |
| 论文代写 / 代改 | 学术不端，平台风险 | 永不 |
| 商业论文买卖 | 同上 | 永不 |

## 2. 核心技术路线（Phase 1 由架构师细化验证）

### 2.1 指纹算法层（多算法融合）
- SimHash（大规模近似去重，快）
- MinHash + LSH（集合相似度，鲁棒）
- n-gram shingle + 余弦相似度（片段级命中）
- 输出统一为"相似度分数 + 命中片段"

### 2.2 语料库层
- 种子语料：开源中文语料（新闻、百科类）先跑通流程
- 积累语料：用户上传文档经脱敏后入库（用户协议授权）
- 注意：语料库版权风险，仅用开源/授权数据

### 2.3 校准层（本项目的核心差异点）
- 用户回传真实查重报告 → 提取真实查重率
- 与系统预查重分数配对 → 监督回归（线性回归起步 → GBDT 迭代）
- 输出：系统分数 → 目标平台分数的映射区间
- 精度目标：平均绝对误差收敛到 5% 以内（随样本增长）

### 2.4 第三方 API 适配层
- 统一适配器接口（平台枚举 + 认证 + 计费 + 限流）
- 模板化接入：配置即接入新平台
- MVP 阶段：接口先预留，未签约平台用模拟实现占位

## 3. 系统架构（选型由架构师在 Phase 1 定，此处为方向）

```
桌面端(PyQt6/其他) ──┐
                     ├──► 后端 API(FastAPI/其他) ──► 任务队列(Celery+Redis) ──► 查重引擎
Web 前端(React/Vue) ─┘                              │
                                                    ├──► 数据库(MySQL/PG)
                                                    ├──► 对象存储(文档原件)
                                                    └──► 校准模型服务(训练/推理)
```

- 查重是耗时任务，必须异步化（队列 + 轮询/回调）
- 桌面端离线模式不依赖服务器即可跑基础查重，在线模式同步校准结果

## 5. 风险与合规

| 风险 | 等级 | 应对 |
|------|------|------|
| 语料库版权 | 高 | 仅用开源/授权语料；用户文档脱敏并签署授权协议 |
| 学术伦理争议 | 中 | 定位为"预检"工具，报告附免责声明，不做代写代改 |
| API 调用成本 | 中 | MVP 以自研引擎为主，第三方 API 做成可选增值 |
| 精度达不到预期 | 中 | 校准模型持续迭代；UI 呈现置信区间而非虚假精确 |
| 服务器与带宽成本 | 低 | 轻量起步，任务异步化控制峰值 |
