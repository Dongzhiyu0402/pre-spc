# 页面设计提示词：登录 / 注册页

> 路由：`/login`、`/register`（Web）｜桌面端同构（QDialog）
> 设计 Token 主题：中性（无强调色堆砌）
> 验收映射：AC-12（注册赠次数）

---

## 1. 页面目标

极简、低摩擦、可信。焦虑用户不想在登录上花时间——字段最少化，错误就近显示。注册完成即赠免费次数（AC-12），文案明示。

## 2. 布局（居中卡片，max-w-2xl 672px）

```
┌────────────────────────────────────┐
│          （居中，垂直居中）           │
│  Logo（文字标）                     │
│  H1：登录 / 创建账号（20px semibold）│
│                                    │
│  [邮箱输入]        ← label 可见      │
│  [密码输入]        ← label 可见      │
│  [昵称输入]（仅注册）                │
│  [登录 / 注册并领取免费次数] 主 CTA   │
│  错误提示（就近，--danger）          │
│  切换链接：没有账号？注册 / 已有账号？登录 │
│                                    │
│  微信扫码登录（可选 P0 简化：先做邮箱）│
└────────────────────────────────────┘
```

## 3. 核心组件与状态

| 组件 | 规范 |
|------|------|
| 输入框 | label 可见（禁仅 placeholder）；focus border --accent + --focus-ring；error border --danger + 就近错误文案；disabled 灰 |
| 主 CTA | Button primary 高 44px；loading 态含 spinner；文案含利益（"注册并领取 3 次免费查重"） |
| 错误提示 | 就近字段下方（--danger），含具体原因（"邮箱已注册，请直接登录"）；不只在顶部 |
| 切换链接 | Ghost 链接（--accent），键盘可达 |
| 密码强度 | 注册页：弱/中/强提示（--warn/--accent/--success），不打断输入 |

## 4. 交互流

1. 进入 /login → 填写 → 提交 POST /auth/login → 成功跳首页
2. 进入 /register → 填写（邮箱/密码/昵称）→ 提交 POST /auth/register → 成功赠次数（AC-12）→ 跳首页
3. 邮箱已存在 → 409 错误就近显示
4. 未登录访问 /report/:id → 跳 /login（带 redirect 参数，登录后回跳）

## 5. 响应式

- 移动端：卡片全宽（padding 16px），输入框 44px 高（触摸目标）
- 桌面端：卡片留白充足，垂直居中

## 6. 文案（禁空洞占位）

- H1：`登录` / `创建账号`
- 注册 CTA：`注册并领取免费查重次数`（具体利益）
- 登录 CTA：`登录`
- 错误：`邮箱已注册，请直接登录` / `邮箱或密码不正确`
- 隐私：`你的论文与账号信息受保护`（muted 小字，回应泄露焦虑）

## 7. 验收映射速查

- AC-12：注册完成 → 免费次数入账 → 用量页可见 ✓
- 未登录访问报告 → 跳登录并回跳 ✓
