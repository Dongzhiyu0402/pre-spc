# 页面设计提示词：报告页

> 路由：`/report/:id`（Web）｜桌面端同构（QTabWidget/QSplitter 变体）
> 设计 Token 主题：Teal + 语义色（--highlight-*）
> 验收映射：AC-05 / AC-06 / AC-07 / AC-08 / AC-09
> 数据源：`GET /api/v1/checks/{id}/report` → `{ est_median, est_low, est_high, confidence, segments, ... }`

---

## 1. 页面目标

让焦虑的毕业生**3 秒内看懂三个问题**：①我大概多少？（预估中值+区间）②我过没过学校线？（阈值线对照）③我该改哪里？（跨线提示 + 高亮片段 + 来源）。诚实呈现"预估区间 + 置信度"，绝不展示虚假精确单一数字（AC-06/AC-08）。

## 3. 核心组件与状态

### 3.1 误差带量规（本页核心，自绘 SVG，勿用单一环形）

| 元素 | 实现 | Token |
|------|------|-------|
| 轨道 | rect，高 8px，radius pill | --gauge-track #F1F2F4 |
| 区间色带 | rect，高 20px，覆盖 [est_low, est_high] 映射到 0–100% 标尺 | --gauge-band rgba(13,148,136,0.18) |
| 中值刻度点 | circle r=7，中心在 est_median，附垂直引导线 | --gauge-median #0D9488 |
| 阈值线 | 垂直 line 虚线 + 顶部标签"学校阈值 20%" | --gauge-threshold #DC2626 |
| 端点文字 | 区间两端 mono 小字 | --font-mono / --muted |
| 标尺刻度 | 0% / 25% / 50% / 75% / 100% 浅刻度 | --meta |

- **状态：样本不足（AC-08）**：色带宽度由 [est_low, est_high] 决定，样本不足时后端返回更宽区间，色带自然变宽；同时展示宽区间提示文案（勿额外造假）
- **状态：跨阈值（AC-07）**：est_high > threshold 时绘制阈值线 + 显示行动指引条；threshold 来自用户设置（默认 20%，可在用量页/设置改）
- **状态：加载**：量规骨架屏（轨道占位 + 微光）
- **状态：空/错误**：报告不存在 → 错误态"报告不存在或已删除" + 返回历史按钮；不展示空量规

### 3.2 指标小卡（3 张）

- 结构：标签（muted sm）+ 数值（mono xl）
- 数值来源：去除引用率 / 去除本人率 / 单篇最大复制比（后端字段）；MVP 若部分指标暂无 → 显示"—"，不造假

### 3.3 章节重复率条

- 结构：章节名（sm）+ 细进度条（6px pill）+ 百分比（mono sm，右对齐）
- 着色规则（等级）：≤10% --success / 10-20% --accent / 20-30% --warn / >30% --danger
- 交互：hover 高亮，点击可滚动定位到全文对应片段

### 3.4 全文高亮视图 + 来源抽屉

- 全文渲染：段落流，行高 1.8（长文阅读），正文 --fg
- 高亮：片段按 `highlight_type`（high/mid/cite/exclude）映射 `--highlight-*` 底色；高亮文字仍为 --fg 深色（对比度 4.5:1）
- 原创片段 = 无底色
- 交互：点击高亮片段 → 描边高亮 + 打开右侧来源抽屉（移动端底部面板）
- 抽屉内容：来源列表行（篇名 / 作者 / 出处 / 年份 / 相似比 mono / "已引用"徽标）+ 展开"原文 vs 来源"对照（左原文右来源）
- 抽屉关闭：X 按钮（Lucide）+ Esc + 点击遮罩
- **无障碍**：高亮同时提供文字标签（如片段开头小标"高重复""引用"），不只靠颜色传达（WCAG 1.4.1）

### 3.5 导出 + 免责声明

- 导出按钮（顶栏，Button primary + download 图标）：下拉选 PDF / HTML（AC-09）
- 导出内容：预估卡 + 指标 + 章节条 + 全文高亮 + 来源列表 + **免责声明常驻**"预估仅供参考，非官方检测报告"
- 导出中：按钮 loading；失败：Toast 错误 + 可重试

## 4. 交互流

1. 进入页面 → 骨架屏加载 → 渲染预估结果卡（中值/区间/置信度先出现，全文后加载）
2. 用户看量规：中值点 → 区间色带 → 阈值线对照
3. 跨线 → 行动指引条出现；用户点"查看高亮片段" → 平滑滚动到全文第一个高重复片段
4. 用户点任意高亮片段 → 来源抽屉打开
5. 用户点导出 → PDF/HTML 下载

## 5. 响应式

- <768px：预估卡上下堆叠（数字在上、量规在下）；三指标卡 1 列或 2 列；来源抽屉改底部面板（高 60vh，可下拉关闭）；全文单栏，对照改为"来源"折叠行
- 触摸目标：片段点击区 ≥44px 高；导出按钮 ≥44px

## 6. 文案（禁空洞占位）

- 标题：`查重报告 · {file_name}`
- 预估卡标签：`预估查重率` / `预估区间` / `置信度`
- 跨线提示：`你的预估区间跨过学校阈值 {threshold}%，建议优先修改高亮片段`
- 宽区间提示：`预估区间较宽，校准样本积累中，结果仅供参考`
- 免责声明：`预估仅供参考，非官方检测报告`
- 空片段：`未发现明显相似片段，继续保持`（低重复时正向反馈，缓解焦虑）

## 7. 验收映射速查

- AC-05：预估中值 + 区间 + 置信度 + 片段高亮 + 来源提示 全部可见 ✓
- AC-06：误差带量规（中值点 + 区间色带）为唯一可视化，无单一环形/单一数字 ✓
- AC-07：阈值线可绘制 + 跨线行动指引 ✓
- AC-08：样本不足 → 宽区间提示，无虚假精确 ✓
- AC-09：导出 PDF/HTML 含免责声明 ✓
