# 页面设计提示词：用量 / 我的页

> 路由：`/usage`（Web）｜桌面端同构（QDialog/QWidget）
> 设计 Token 主题：中性 + Teal 强调
> 验收映射：AC-04 / AC-13 / AC-14 / AC-15
> 数据源：`GET /api/v1/users/me/usage`、`POST /api/v1/calibration/reports`、`GET /api/v1/calibration/status`

---

## 1. 页面目标

用量透明（防滥用 + 收钱）+ 校准回传入口（本项目差异化核心——鼓励用户回传真实报告换免费次数，驱动数据飞轮）。隐私承诺可视化。

## 2. 布局

```
┌─────────────────────────────────────────────────────┐
│ 顶部导航（返回）                                       │
│ H1：用量与账户（20px semibold）                        │
├─────────────────────────────────────────────────────┤
│ 账户概览卡（2 列）：                                    │
│   [免费查重次数] 3 次剩余   [积分] 120（查重优先扣积分）  │
│   [校准样本数] 12 条（距 30 条训练阈值）                │
│   [预估精度] MAE ±4.2%（模型 v0.3）                    │
├─────────────────────────────────────────────────────┤
│ 学校阈值设置卡：                                       │
│   我的学校查重率阈值： [20] %（可编辑，默认 20，5-50）   │
│   说明：报告页阈值线将按此绘制（AC-07）                  │
├─────────────────────────────────────────────────────┤
│ 校准报告回传卡（差异化核心入口，Teal 强调）：             │
│   标题：回传真实查重报告，让预估更准                     │
│   说明：上传你在知网/维普/万方的真实报告，我们提取真实率   │
│          与预查重配对校准，回传 1 份送 1 次免费查重        │
│   [选择报告文件] [选择平台] [真实查重率] → [回传]         │
│   回传状态：待校验 / 已配对 / 格式无效(重试)              │
│   隐私：仅提取查重率数字，报告文件加密存储                 │
├─────────────────────────────────────────────────────┤
│ 历史报告（引用 /history 列表，可选快捷入口）             │
└─────────────────────────────────────────────────────┘
```

## 3. 核心组件与状态

| 组件/状态 | 规范 |
|-----------|------|
| 账户概览卡 | 4 个小卡：label（muted sm）+ 数值（mono xl）；积分/次数变更时数值微动效（仅 opacity/transform） |
| 学校阈值设置 | InputNumber 5–50，默认 20；保存后 Toast"阈值已更新，报告页将按新阈值显示"（AC-07 联动） |
| 校准回传表单 | 文件选择 + 平台 Select（知网/维普/万方）+ 真实查重率 InputNumber（0–100）；提交 POST /calibration/reports |
| 回传状态 | 待校验（spinner）/ 已配对（success 绿 + "已送 1 次免费查重"）/ 格式无效（danger + 重试按钮，AC-14） |
| 模型状态 | 校准样本数 + 训练状态；样本 <30 显示"样本积累中，预估区间较宽"（AC-15 联动提示） |
| Empty | 无校准样本：引导"回传第一份真实报告" + 说明价值 |
| Error | 回传失败：明确错误 + 重试，不消耗次数 |

## 4. 交互流

1. 进入 /usage → GET /users/me/usage + /calibration/status → 渲染概览
2. 用户改学校阈值 → 保存 → 报告页阈值线联动
3. 用户回传真实报告 → 选文件/平台/填真实率 → POST → 状态流转 → 免费次数 +1
4. 免费次数为 0 时（AC-04）：任意查重入口跳转至此 → 引导回传报告换次数或充值

## 5. 响应式

- 移动端：概览卡 2 列；回传表单单列；触摸目标 ≥44px

## 6. 文案（禁空洞占位）

- 回传卡标题：`回传真实查重报告，让预估更准`
- 说明：`上传你在知网/维普/万方的真实查重报告，我们只提取查重率数字用于校准，回传 1 份送 1 次免费查重`
- 隐私：`报告文件加密存储，仅用于校准，不会公开`
- 阈值说明：`报告页的学校阈值线将按此绘制`

## 7. 验收映射速查

- AC-04：次数 0 → 跳转此页 ✓
- AC-13：查重优先扣积分，余额实时可见 ✓
- AC-14：回传有效 → 提取真实率配对入库 ✓
- AC-15：样本 ≥30 → 触发训练提示，预估区间参数更新 ✓
- AC-07：阈值可配置，报告页联动 ✓
